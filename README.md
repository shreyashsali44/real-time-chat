# 💬 Real-Time Chat Application

A full-stack real-time chat application built with **React Native (Expo)** and **Node.js + Express + Socket.io + MongoDB**.

## 🌟 Features

### Core Features
- ✅ Real-time messaging with Socket.io
- ✅ Send and receive messages instantly
- ✅ Message persistence with MongoDB
- ✅ View chat history after refresh
- ✅ Message timestamps
- ✅ REST APIs for messages and users
- ✅ Graceful connection/disconnection handling

### Bonus Features
- ✅ Username-based dummy authentication
- ✅ Typing indicator with animated dots
- ✅ Online/offline user status
- ✅ Message read/delivered status indicators
- ✅ MongoDB message storage
- ✅ System messages (join/leave notifications)
- ✅ Auto-scroll to latest messages
- ✅ Message grouping by sender
- ✅ Color-coded user avatars
